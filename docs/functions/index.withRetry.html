      Wraps an async operation with automatic retry logic and exponential backoff.

      The operation will be called up to maxRetries + 1 times total. On each failure that is deemed retryable, the function waits for the computed backoff delay then tries again. If the final attempt also fails, the last error is re-thrown.

      Retry attempts are reported via the optional onRetry callback, which receives the current attempt number (1-based), the delay applied, and the error that caused the retry. This can be used for logging without violating the no-console lint rule in the SDK itself.

      Example

      const data = await withRetry(
        () => fetch(url).then((res) => res.json()),
        resolveRetryConfig({ maxRetries: 3 }),
        (attempt, delayMs) => console.log(`retry ${attempt} in ${delayMs}ms`),
      );
